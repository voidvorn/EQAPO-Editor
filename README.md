## 一、软件概述

EQAPO Editor 是一个用于管理和监控 **Equalizer APO（EQ APO）** 均衡器配置文件的图形化工具。它以图形均衡器、声道平衡、自动 EQ、按应用自动切换配置等方式，让用户无需手动编辑 EQ APO 的 `config.txt` 文本文件，即可完成音频调校。

### 核心能力

- **图形均衡器**：可视化调节扬声器（输出）与麦克风（输入）的频段增益，支持 15 频段、31 频段与可变频段（自由增删频段、编辑中心频率）。
- **频段导入 / 导出**：支持导入与导出 `GraphicEQ`、`ParametricEQ`、`FixedBandEQ` 三种格式的频段文件。
- **前置放大与声道平衡**：统一音量增益与左右声道独立平衡调整。
- **实时监听**：直接监听处理后的音频输出（AudioMonitor）。
- **按应用自动切换**：检测前台正在运行的程序，自动应用该应用专属的 EQ 配置。
- **默认配置（原“驻留配置”）**：可创建一个默认配置，当专属配置应用退出后自动切回。
- **自动 EQ（AutoEQ）**：内置 AutoEQ 数据库浏览器，支持搜索、仓库浏览/更新、从 GitHub 下载数据库，并解析应用耳机/设备的频响校准数据。
- **多语言界面**：支持简体中文、繁体中文、英文。
- **跟随系统美学**：深色主题、系统托盘、开机自启等。

## 二、安装与启动

### 2.1 运行前置条件

- Windows 10 / Windows 11（建议 64 位）。
- 已安装 **Equalizer APO**（本工具用于管理其配置文件目录）。
- 需要底层音频处理时，系统已安装并配置了 EQ APO 的驱动组件。

### 2.2 启动方式

- 双击 `EQAPO_Editor.exe` 或直接运行 `EQAPO_Editor.py` 启动程序。
- 首次启动默认显示 **扬声器** 标签页（主页面）。

### 2.3 启动行为

- 若启用了 **系统托盘**，程序启动后将以托盘图标形式驻留后台，主窗口不弹出。
- 若未启用托盘，则直接显示主窗口。
- 若配置了“静默启动”的扩展应用，启动约 0.2 秒后会自动拉起这些应用。

### 2.4 首次使用流程

1. 在 **设置 → 配置管理** 中选择 EQ APO 的配置文件目录（存放 `config.txt` 的文件夹）。
2. 在 **扬声器 / 麦克风** 标签页中选择对应的音频输入/输出设备。
3. 调节频段增益、前置放大与声道平衡。
4. 点击“安装”将配置写入 EQ APO，使设置生效。

## 四、扬声器 / 麦克风标签页

两个标签页结构一致，一个针对 **输出设备（扬声器）**，一个针对 **输入设备（麦克风）**。

### 4.1 主要控件

| 控件 | 作用 |
|------|------|
| 设备下拉框 | 选择音频输入/输出设备，右侧刷新按钮可刷新设备列表 |
| 启用开关 | 启用/禁用该设备的 EQ 处理 |
| 频段模式 | 切换均衡器工作频段：15 频段 / 31 频段 / 可变频段 |
| 频段滑块 | 可视化调节各频段增益；支持直接编辑中心频率（Hz）与增益（dB） |
| ＋ / － 按钮 | 可变频段模式下，新增 / 删除频段 |
| 导入频段 | 导入 GraphicEQ / ParametricEQ / FixedBandEQ 频段文件 |
| 导出频段 | 将当前频段设置导出为文件 |
| 前置放大（Preamp） | 全局统一音量增益补偿 |
| 声道平衡 | 打开声道平衡对话框，独立调节左/右增益与平衡 |
| 监听下拉框 | 打开 / 关闭实时监听（AudioMonitor） |
| AutoEQ | 打开 AutoEQ 数据库对话框，搜索并应用设备频响校准 |

### 4.2 使用说明

- 拖动任一频段滑块会立即生效并（延迟约 300ms 后）自动保存到配置文件。
- 修改设备、前置放大或声道平衡后，配置会自动写回 EQ APO。
- 切换到“可变频段”后，可点击 ＋ / － 增删频段，或直接编辑频段中心频率（Hz）与增益（dB）。
- “导入频段 / 导出频段”支持 GraphicEQ、ParametricEQ、FixedBandEQ 三种格式，便于与 AutoEQ 数据或外部文件互通。
- 将“监听”下拉框设为“打开监听”可实时听到调整后的效果，便于主观调音。

## 五、配置标签页（按应用自动切换）

该标签页用于管理“不同应用使用不同 EQ 配置”的自动切换规则。

### 5.1 顶部工具栏

| 控件 | 作用 |
|------|------|
| ＋（添加按钮） | 添加一个新的应用并为其配置专属 EQ |
| 自动切换开关 | 开启后，检测到前台切换到已配置应用时自动切换配置 |
| 创建默认配置开关 | 开启后创建一个默认配置；当专属配置应用退出后自动切回默认配置 |
| 排除默认配置开关 | 开启后，切换时排除默认配置的干扰 |
| 通知开关 | 开启后，配置切换时弹出右下角通知弹窗 |

### 5.2 应用卡片

- 每个已配置应用以 **卡片** 形式展示，包含：应用图标、应用名称、当前配置状态。
- 选中某张卡片后，可为该应用绑定专属的 EQ 配置。
- 底部提示文字会说明添加应用与保存规则的用法。

### 5.3 自动切换原理

- 通过 **前台应用检测器**，定时识别当前处于前台的窗口/进程。
- 当前台切换到已配置应用时：
  - 自动套用该应用的专属 EQ 配置；
  - 若开启通知开关，则在 **屏幕右下角** 弹出配置切换通知（悬停可暂停自动关闭）。
- 当离开已配置应用回到其他程序时，自动恢复默认配置（除非启用了“创建默认配置 / 排除默认配置”）。

## 九、自动 EQ（AutoEQ）功能

在扬声器/麦克风标签页点击 **AutoEQ** 打开 **EQAPO AutoEQ 数据库** 对话框，用于浏览、搜索并应用耳机/设备的频响校准数据。

### 9.1 搜索与筛选

- **搜索框**：输入耳机名称实时搜索（支持模糊匹配与相似度排序）。
- **EQ 类型**：下拉切换 `GraphicEQ` / `ParametricEQ` / `FixedBandEQ` 三类数据源。
- **结果表格**：三列展示 耳机 / 测量器 / 方法，各列可在设置中开关显示。

### 9.2 数据获取与仓库管理

| 能力 | 说明 |
|------|------|
| 浏览本地仓库 | 从本地加载 EQ 数据：启用“从文件夹加载 EQ 数据”时选择目录扫描，否则选择 zip 压缩包解析 |
| 更新本地仓库 | 从 GitHub 下载 AutoEQ 仓库 zip 包并解析，失败自动重试、可取消 |
| 刷新缓存 | 重新扫描已缓存的数据（`AutoEqData/EQ/*.pkl`） |

下载与解析过程在后台工作线程中执行，不阻塞界面；进度条与（可选）日志框实时反馈。

### 9.3 应用数据

- 双击表格条目或选中后点击 **使用**，程序读取该设备的 EQ 数据并**自动应用到当前标签页的图形均衡器**（ParametricEQ / FixedBandEQ 会先转换为频点-增益曲线用于显示）。
- 在 **设置** 对话框中可配置：搜索范围（三列的显示开关）、仓库管理（显示日志框 / 从文件夹加载 EQ 数据）。

### 9.4 数据缓存

- 已下载数据缓存在 `AutoEqData/EQ/` 目录（`GraphicEQ.pkl`、`ParametricEQ.pkl`、`FixedBandEQ.pkl`），扫描缓存位于 `AutoEqData/cache/scan_cache.pkl`，避免重复下载。
- 按应用专属配置会分别记忆最近一次选择的条目。

## 十一、常见问题

### Q1：为什么启动后没有窗口？
如果启用了系统托盘且“应用行为→系统托盘”为开启状态，程序会驻留托盘。请查看屏幕右下角托盘区域点击图标。

### Q2：如何确认 EQ 配置已生效？
调节完成后点击 **设置 → 配置管理 → 安装**，并确认已选择正确的 EQ APO 配置文件目录。

### Q3：自动切换没有生效？
请检查：① 已在配置页添加对应应用；② 自动切换开关已开启；③ 前台应用与配置的应用进程名称/路径匹配正确。

### Q4：想恢复默认设置？
在 **设置 → 复位与维护 → 复位设置** 一键恢复软件默认设置。

### Q5：CPU 占用目标
软件设计上追求在启动与配置切换时保持低 CPU 占用（以事件驱动代替轮询阻塞），并采用工作线程处理监听与 EQ 数据扫描。

## 十二、模块说明

程序采用模块化设计，各模块分工如下：

### 12.1 主程序

| 文件 | 作用 |
|------|------|
| **EQAPO_Editor.py** | 程序入口与主窗口 `EQAPOEditor`。负责整体逻辑编排：5 个标签页的搭建、配置文件读写与监控、设备刷新、系统托盘、通知弹窗、自动切换触发、深色主题、退出清理等。 |

### 12.2 均衡器与音频接口

| 文件 | 作用 |
|------|------|
| **Graphic_EQualizer.py** | 图形均衡器主标签页 `EQTab`，是核心功能区域。提供 15/31/可变频段切换、频段增删（＋/－）、频段中心频率（Hz）与增益（dB）直接编辑、导入/导出频段文件（GraphicEQ/ParametricEQ/FixedBandEQ）、设备选择与刷新、前置放大、监听下拉框、AutoEQ/声道平衡请求等。同时定义复用控件：`ToggleSwitch`（开关）、`ForceDownComboBox`（强制向下展开的下拉框）、`RefreshButton`（刷新按钮）、`ArrowDoubleSpinBox`（带箭头的数值输入框）、`FrequencyBandWidget`（频段滑块）、`PreampWidget`（前置放大）。 |
| **AudioMonitor.py** | 音频实时监听器 `AudioMonitor`。在独立线程中采集输入/输出设备音频，用于实时预览 EQ 处理后的效果。 |

### 12.3 功能对话框

| 文件 | 作用 |
|------|------|
| **AutoEQ_Dialog.py** | AutoEQ 数据库对话框 `AutoEQDialog`。提供实时搜索（模糊匹配）、EQ 类型切换（GraphicEQ/ParametricEQ/FixedBandEQ）、本地仓库浏览/更新、GitHub 下载与解析、设置对话框等功能。同时定义 `parse_parametric_to_graphic()`（ParametricEQ/FixedBandEQ 转频点-增益）、`DownloadWorker`（下载线程）、`DirScanWorker`（目录扫描线程）、`ScanWorker`（pkl 缓存扫描线程）、`DownwardComboBox`（强制向下展开的下拉框）。 |
| **ChannelBalance_Dialog.py** | 声道平衡对话框 `ChannelBalanceDialog`。提供左右声道增益与平衡滑块，通过 `balanceChanged` 信号实时通知主窗口。 |

### 12.4 窗口与系统集成

| 文件 | 作用 |
|------|------|
| **Custom_window.py** | 自定义无边框窗口基类 `CustomWindow`，提供深色标题栏、窗口拖动等；同时封装程序图标查找（支持外置/内置/PyInstaller/Nuitka）与临时资源文件加锁保护（防误删）。 |
| **Automatic_startup.py** | 开机自启模块 `AutomaticStartup`。通过 Windows 启动文件夹创建 `EQAPO Editor.lnk` 快捷方式实现开机自启，支持启用/禁用/状态查询。 |

### 12.5 国际化

| 文件 | 作用 |
|------|------|
| **Translation.py** | 多语言翻译模块。维护中/繁/英文本字典，提供 `tr()` 翻译函数、语言切换与 Qt 系统翻译器安装。 |

### 12.6 配置与自动切换

| 文件 | 作用 |
|------|------|
| **auto_config_switch.py** | 自动配置切换的核心配置管理。定义 `ConfigKeys` 及所有相关设置项（自动切换、通知、默认配置（驻留）、语言、扬声器/麦克风启用、写入模式等）的读写。 |
| **app_config_manager.py** | 应用配置管理器 `AppConfigManager`。使用 `QSettings` 持久化每个应用的路径、名称、输入/输出配置与检测配置。 |
| **app_detector.py** | 前台应用检测器 `AppDetector`。定时检测当前前台窗口/进程，切换至已配置应用或离开时发出信号，触发自动切换。 |
| **process_detector.py** | 进程检测模型。定义 `MatchMode`（精确/别名/通配符/正则/路径/命令行）与 `ProcessInfo`，支持多维度高灵活度的进程匹配。 |
| **extensions_manager.py** | 扩展应用管理 `ExtensionConfigManager` 与 `ExtensionsPage`。持久化扩展应用列表，并支持静默启动。 |

### 12.7 模块协作流程

```
用户操作 EQ 标签页
        │
        ▼
EQTab（Graphic_EQualizer）
        │  AnythingChanged / AutoEQRequested / ChannelBalanceRequested
        ▼
EQAPOEditor（主窗口）
        │  ★ 读写配置文件目录（config.txt）
        │  ★ 调用 Install/Uninstall
        ▼
AppDetector + ProcessDetector（检测前台应用）
        │
        ▼
auto_config_switch（自动切换）+ app_config_manager（应用配置）
        ▼
应用到 EQTab → 写入 EQ APO → 生效
```
